Privacy Policy

Last updated: 17 November 2026

1. Summary

Peakverse Publisher is an internal desktop tool that publishes Peakverse's own videos to Peakverse's own social media accounts. It does not collect data from other people.

2. Data we access

When we connect one of our own accounts (TikTok, Instagram or YouTube), the platform gives the tool an access token and basic profile information of that account, such as its username and ID. The tool uses them only to upload our videos, set their captions and read the views of our own posts.

3. Where data is stored

Tokens and settings are stored locally, encrypted, on the computer that runs the tool. We do not send them to any server of ours and we do not sell or share them.

4. Data of other users

The tool does not log in other users, does not read their profiles or messages and does not store any personal data about them.

5. Website

This website is a static page hosted on GitHub Pages. It has no forms, no accounts and no tracking cookies of ours. GitHub may log basic technical data such as IP addresses for security; see the GitHub Privacy Statement.

6. Deleting data

We can disconnect an account at any time, which deletes its token from the tool. You can also revoke access from the security settings of each platform.
